# Day Zero skills

These files tell a coding agent which Day Zero table to create. The agent still follows [ai.md](https://dayzero.run/ai.md) for the CLI, the site key, and deploy.

- [Email subscription](./email-subscription.md) — signup, newsletter, or notify-me list. Label: `email_subscription`
- [User enquiry form](./user-enquiry-form.md) — contact, question, or enquiry. Label: `user_enquiry`
- [Share button](./share-button.md) — share click or copy-link count. Label: `share_button`
- [Launch waitlist](./waitlist.md) — one launch, product, or idea. Label: `waitlist`
- [Guestbook](./guestbook.md) — public note or short comment. Label: `guestbook`
- [Poll vote](./poll-vote.md) — one row per vote. Label: `poll_vote`
- [Reaction](./reaction.md) — like, love, or other reaction count. Label: `reaction`
- [Star rating](./star-rating.md) — score from 1 to 5. Label: `star_rating`
- [RSVP](./rsvp.md) — coming or not, plus guests. Label: `rsvp`
- [Scoreboard](./scoreboard.md) — game score, quiz result, or leaderboard row. Label: `scoreboard`
- [Link click](./link-click.md) — click on one outbound link. Label: `link_click`
- [Club signup](./club-signup.md) — join a club, class, or group. Label: `club_signup`
- [Booking request](./booking-request.md) — ask for a time. Label: `booking_request`
